## Prérequis

### Debian en mode `Terminal`
| Composant     | Minimum |
| ------------- | ------- |
| Processeur    | 1 cœur  |
| Mémoire RAM   | 512 Mo  |
| Espace disque |  5 Go   |

### Debian en mode `Bureau` (Xfce)
| Composant     | Minimum         |
| ------------- | --------------- |
| Processeur    | 2 cœurs         |
| Mémoire RAM   | 2 - 4 Go        |
| Espace disque | 20 - 35 Go      |
