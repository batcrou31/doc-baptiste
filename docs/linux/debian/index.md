## Prérequis

     
| Composant         | Debian en mode `terminal` | Debian en mode `interface graphique` (Xfce) |
| ----------------- | ----------------------------- | ------------------------------------- |
| **Processeur**    | 1 cœur                | 2 cœurs                       |
| **Mémoire RAM**   | 256 - 512 Mo                        | 2 - 4 Go                                  |
| **Espace disque** | 5 Go                         | 20 - 35 Go                                 |
