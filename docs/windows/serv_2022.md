# Serveur 2022

## Divers

### Création carte réseau virtuelle

!!! warning "Attention"

    Il faut d'abord créer un commutateur virtuel __LAN HYPER-V__ dans _Gestionnaire de serveur > Serveur local > Association de cartes réseau.

schéma explicatif :

<figure markdown="span">
  ![Image title](../assets/windows/serv_2022/SRV22_CR.png){ width="1000" }
</figure>

``` shell
New-VMSwitch -Name "Externe" -NetAdapterName "LAN HYPER-V" -AllowNetlbfoTeams $true -AllowManagement $true
```
